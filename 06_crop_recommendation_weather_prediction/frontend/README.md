# Farmer Dashboard

A beautiful React dashboard for farmers to get crop recommendations and weather predictions.

## Setup

1. Install dependencies:

```bash
npm install
```

2. Start development server:

```bash
npm run dev
```

3. Build for production:

```bash
npm run build
```

## Features

- 🌾 Crop recommendations based on weather conditions
- 🌤️ Weather predictions
- 📊 Interactive charts
- 💡 Farming tips
- 🎨 Beautiful farmer-themed UI
